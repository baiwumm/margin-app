# Margin 小程序 · 视觉与交互规范

> **基准（D10）**：以 `demo/` 5 张图为唯一视觉基准（暖白 `#F6F3EE` + 柠檬绿 `#D7F94C` + 大圆角 + 悬浮胶囊）。margin 站点的终端风装饰（Maple Mono、光标光晕、颗粒噪点、`#f2f5ec` 底）一律不进小程序，只嫁接品牌元素（D9）。
> demo **只有浅色稿**：浅色令牌 = 最终基线；`.theme-dark` 是推导起点，M1 打样第 2 项真机校准。

## 1. 五屏结构（页面验收基准）

| 屏 | 结构（自上而下） |
| --- | --- |
| **首页** | ① Hero 大图（顶部叠加胶囊公告 + 日期文案，图下缘圆角）② 搜索胶囊（「哈喽，想看些什么 **内容** 呢~」关键词高亮）③ 公告条（D32：`announcement = null` 时整条隐藏不占位；有条时整条可点 → 关于页）④ 快捷导航（5 个圆形 emoji 图标 + 文字）⑤ 热门标签（左跨行大卡 + 右两小卡的双列错落网格，色块渲染）⑥ 最新推荐（tabs：默认 / 置顶 / 最新 / 最旧 + **纯文字卡**列表，D28） |
| **标签** | 居中标题「标签」+ 双列色块卡（标签名 + 「共 N 篇笔记」）+ 空态「呜呜，没有更多数据了~」 |
| **图库** | 居中标题「图库」+ 横滚筛选胶囊（「全部」+ 3 个画廊名 + 各自 `photoCount`，D27）+ 双列图片网格（左下叠文件名）+ 空态 |
| **瞬间** | 左上「2026 / 本月」双胶囊 + 居中标题「我的日常」+ 月份横滚选择器（端上按 `pubDatetime` 聚合月份轴）+ 瞬间卡片（头像 + 昵称 + 日期 + 详情 / N 张图 / 3 列图网格 / 点赞收藏）+ 右下悬浮「＋ 发布瞬间」（**一期隐藏**，个人主体 UGC 风险） |
| **我的** | 顶部渐变 + Hero（圆形头像 + 昵称 + 一句话简介）+ 八宫格入口（我的收藏 / 阅读记录 / 笔记归档 / 友情链接 / 数据看板 / 关于项目 / 联系博主 / 免责声明——demo 的投票中心 / 恋爱日记 / 通知公告去掉）+ 其他功能列表（偏好设置 / 免责声明 / 关于项目）+ 底部版权行 |

**全局**：底部悬浮胶囊 tabBar（5 tab，选中带色，非通栏）；右侧悬浮操作组（回顶 + 设置 + 头像，滚动超一屏出现）；全部页面 `navigationStyle: custom`，标题居中显示在内容流中。

⚠️ demo 是 uni-halo v3.x 实机截图，不是为本项目设计的稿子——品牌位与文案必须全部替换；本地 `uni-halo` 2.0.10 的配色与 demo 完全不同，只有页面结构可参考。

## 2. 设计令牌（写入 `src/styles/tokens.css`）

浅色数值全部由 demo 图**程序化采样**得出（非肉眼估计），为最终基线：

```css
:root {
  /* 品牌 */
  --c-accent:        #D7F94C;   /* 柠檬绿，主强调色 */
  --c-accent-soft:   #E0EF93;   /* 浅强调，hero 叠加 / 选中底 */
  --c-accent-ink:    #2D2F2E;   /* 强调色上的文字 */

  /* 表面 */
  --c-bg:            #F6F3EE;   /* 页面底色（暖白） */
  --c-surface:       #FCFAF8;   /* 卡片 */
  --c-surface-alt:   #F2EFEB;   /* 次级卡片 / 输入框 */
  --c-border:        #ECEBEB;

  /* 文字 */
  --c-text:          #2D2F2E;
  --c-text-sub:      #909399;
  --c-text-weak:     #B8B8B8;

  /* 圆角 */
  --r-sm: 12rpx; --r-md: 20rpx; --r-lg: 28rpx; --r-full: 999rpx;

  /* 间距 */
  --sp-page: 24rpx; --sp-gap: 20rpx;
  --sp-1: 8rpx; --sp-2: 16rpx; --sp-3: 24rpx; --sp-4: 32rpx; --sp-5: 48rpx;

  /* 阴影（暖白底 → 极淡投影 + 描边，避免发灰） */
  --sh-card: 0 2rpx 24rpx rgba(45, 47, 46, 0.04);
  --sh-float: 0 8rpx 32rpx rgba(45, 47, 46, 0.10);

  /* 字号（正文可调，见偏好设置） */
  --fs-body: 30rpx; --fs-cap: 24rpx; --fs-title: 34rpx; --fs-h1: 40rpx;
  --lh-body: 1.75;
}
```

暗色为推导起点（demo 无暗色稿），M1 真机校准；构建期对每个 accent 背景 × ink 组合跑 WCAG 断言（≥4.5:1 正文 / ≥3:1 大字）：

```css
.theme-dark {
  --c-bg: #1A1B19; --c-surface: #232522; --c-surface-alt: #2A2C29;
  --c-text: #EDEFEA; --c-text-sub: #9AA09A; --c-border: #33362F;
  --c-accent:      #A8C63A;   /* 降明度版柠檬绿，大面积填充用 */
  --c-accent-soft: #35401F;   /* 选中底/hero 叠加：暗底 + 亮字 */
  --c-accent-ink:  #D7F94C;   /* 强调位文字反用最亮的绿 */
  --c-text-weak:   #6E726C;
  --sh-card: 0 2rpx 24rpx rgba(0, 0, 0, 0.35);
  --sh-float: 0 8rpx 32rpx rgba(0, 0, 0, 0.55);
}
```

> **暗色下 `#D7F94C` 的定调**：浅色 = 大面积亮底 + 深字；暗色反过来——只做**描边、图标、小面积高亮 + 亮字**。M1 在「tab 选中态」和「标签色块卡」两处一起验，否则暗色验收集中返工。

**几何实测**：画布 430×932pt @3x；页面边距 24rpx、列间距 20rpx、双列卡宽 341rpx（校验 `(750 − 24×2 − 20) / 2 = 341` ✅）。

## 3. 标签色板（D22 / D31）

- 10 档公式色板：`h = (index × 36) % 360`；浅色 `hsl(h, 58%, 80%)`、暗色 `hsl(h, 22%, 26%)`；`ink` 浅配 `#2D2F2E`、暗配 `#EDEFEA`。
- 取色 = 该标签按 count 降序后的**序号 % 10**（非 hash：新增标签只在尾部插色，不打乱已有配色）。
- 构建期对 10 档 × 明暗两套跑 WCAG 对比度断言（`ink` 与底色 < 4.5:1 报错，硬规则）。
- S/L 是「与柠檬绿同族、明度统一」的推导起点，**明度统一 ≠ 好看**；M1 真机校准后把 20 个色值写进 api-contract.md。

## 4. 关键交互规范

| 交互 | 规范 |
| --- | --- |
| 列表入场 | 逐项错峰上浮（`delay = index × 50ms`，封顶 300ms） |
| 下拉刷新 / 上拉加载 | 页面级 `enablePullDownRefresh`；`onReachBottom` 触发 `usePagination.next()`，无更多时 toast |
| 图片预览 | 统一 `Taro.previewImage({ current, urls, indicator: 'number', loop: true })` |
| 长按图片 | 转发 / 保存到相册（D16，需隐私指引 + `openSetting` 容错） |
| 长按正文 | 复制文本 |
| 返回顶部 | 滚动超一屏显示悬浮按钮，平滑回顶 |
| 空态文案 | 区分「未输入」与「无结果」 |
| 分享 | `onShareAppMessage` 用 OG 图（`/posts/<slug>/index.png`，现成红利）；朋友圈 `onShareTimeline` 同图复用 |
| 深色模式 | `Taro.onThemeChange` 跟随系统；偏好设置可强制浅色 / 深色 |

## 5. 字体策略

- **不打包中文字体**（子集化也常在 1MB+）。
- 正文系统字体栈：`-apple-system, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif`。
- 代码块可用仅含拉丁字形的 Maple Mono 子集（约 20–40 KB）；包体紧张则降级系统 `monospace`。

## 6. 小程序 CSS 硬约束（M1 打样必须撞到）

| 约束 | 影响 | 应对 |
| --- | --- | --- |
| `backdrop-filter`（毛玻璃） | 安卓低版本 / 部分机型不支持 → 悬浮 tabBar 失效变透明 | 降级「半透明白 + 1rpx 描边 + 淡阴影」 |
| `position: sticky` | 安卓不稳 | 吸顶改 `scroll-view` + 动态 class |
| 选择器限制 | 不支持 `*` 通配、部分伪类与属性选择器 | 显式书写，禁用通配符 |
| webfont | 不支持普通 `@font-face` 外部字体 | 系统字体栈 + 代码块拉丁子集（可选项） |
| 大面积 `filter: blur()` | 安卓性能差、掉帧 | 静态图或缩小作用范围 |

## 7. Tailwind 使用边界

- ✅ 用原子类写间距 / 圆角 / 字号 / 颜色 / flex（覆盖日常约 80%）。
- ❌ 不要指望：`space-x-*` / `divide-*` / `group-hover` / `peer` / 复杂 arbitrary value——手写 WXSS。
- ✅ 设计令牌一律走 CSS 变量——暗色与偏好设置只换根变量，不改类名。
- ⚠️ **Tailwind v4 必须配 weapp-tailwindcss v5**（v5 才支持 v4，D37）。

### tabBar 实现路线（Q8，M1 打样第 3 项当场定案）

| 路线 | 做法 | 代价 |
| --- | --- | --- |
| **A. `tabBar.custom = true` + `custom-tab-bar/`（倾向）** | 保留 `switchTab` 语义与页面缓存，胶囊自绘 | 每次 `onShow` 手动同步选中态；键盘遮挡、cover-view 层级老坑 |
| **B. 页面内自绘 + 普通路由** | 样式最自由 | 失去 tab 页面缓存——切回首页重建、滚动位置丢失 |

倾向 A：切 tab 保滚动位置是内容型产品的体感底线。这条决定 `app.config.ts` 路由结构，铺量后再改 = 全量返工，必须在打样时定案。

## 9. 有意偏离声明（验收时别当 bug 查）

- **文章卡无图（D28）**：文章卡 = 纯文字卡（标题 + 摘要 + 标签 + 日期 + 阅读时长），与站点网页版一致、与 demo 的有图卡**有意偏离**。视觉重量靠排版（字号层级 / 标签胶囊 / 留白节奏）撑；M1 专门看一屏纯文字卡是否单薄——显单薄就加信息密度与分隔节奏，**不把封面加回来**。
- 页面底色用 demo 暖白 `#F6F3EE`，非 margin 站点的 `#f2f5ec`（有意差异，与卡片/阴影系统更协调）。
