## 6. 腾讯云接入商核查（已闭环）

**背景**：域名在腾讯云备案（接入商 = 腾讯云），实际解析到 Cloudflare 境外 IP，不满足「实际解析 IP 归属须与接入服务商一致」的核查项。

**腾讯云智能客服答复要点（2026-09-28，截图留档于 git 历史）**：已备案服务的主域名或实际使用的子域名，至少须有一条解析指向腾讯云中国大陆资源；**仅新增一个不承载业务的境内子域名，无法保证核查通过**；若业务全程使用境外资源，客服建议「取消腾讯云接入」。

**判定与处置**：

1. 占位子域式方案被官方口径否决；「子域承载真实业务」= 部分内容迁境内，属架构迁移，成本远高于风险，不做。
2. **处置 = 接受风险 + 端上离线快照兜底**（快照与 prefs 不参与 LRU 淘汰，见 api-contract.md §7）。前置已完成：控制台无核查待办、预留手机/邮箱可达。
3. ⚠️ **客服建议的「取消腾讯云接入」不可照做**：取消接入 → 无接入信息 → 空壳网站 → 管局注销备案 → `request` 合法域名失效 → 小程序不可用。
4. **升级路径（仅真收到整改通知时启用）**：把 `/api/v1/**` 的 JSON 迁腾讯云 COS 境内 region，或整站迁微信云开发静态托管；`assetBase` 下发的切换口子已预留，端上零改动。

**整改机制备查**：核查不通过会连续两次电话 + 邮件/短信/站内信通知；延期最多 2 次、每次 ≤5 个工作日；逾期未整改 → 取消接入或管局注销。

## 7. 境外托管的根本张力（接受）

风险链：内容与请求由 Cloudflare 境外节点响应 ↔ ICP 备案实质要求「服务在境内」→ 批量整改 → 极端情况注销备案 → 合法域名失效。**不改架构的理由**：改造成本远高于风险（低概率、慢变量）；同类「境内备案 + 境外托管」组合普遍正常运营；微信侧备案校验已通过。**兜底**：端上冷启动失败回退 `wx.setStorage` 里上次成功的全量快照，展示「离线内容（最后更新于 X）」而非白屏。

## 10. 用户隐私保护指引（M5 提审前）

- 后台配置指引，**声明项与代码实际调用逐项一致**（多写少写都被拒）；一期声明 `saveImageToPhotosAlbum`。
- `saveImageToPhotosAlbum` 被拒绝后**不会再次弹窗**，必须走 `wx.openSetting` 引导，容错代码不能省。
- 隐私口径：不采集设备信息、不接第三方埋点、不请求非必要权限。

### 10.1 配置入口与生效口径（2026-10-08 已配好并实测）

- **入口 = 小程序后台 → 设置（账号设置）→ 页内 tab「服务内容声明」→ 用户隐私保护指引 → 修改**。
  旧教程写的「设置 → 功能设置 → 用户隐私保护指引」已作废（社区里一堆人按老路径找不到）；个人主体同样有此页。
- 已声明项：**相册（仅写入）**（官方信息项 key = `AlbumWriteOnly`，对应接口 `wx.saveImageToPhotosAlbum`），用途 = 「保存图片」；联系方式 = 邮箱 `me@baiwumm.com`。后台状态 = 「已更新」。
- **生效范围**：改完保存即对**开发版/体验版**生效（我们取证用的就是开发版），正式版随下一次提审同步 ⇒ 步 7 的运行时验证不必等发版。
- **两层授权要分清**（这是取证时最容易误判的地方）：
  ① *声明层* = 后台指引。没勾上时调用直接返回 `api scope is not declared in the privacy agreement`。
  ② *用户层* = `scope.writePhotosAlbum` 的系统弹窗，首次调用一定会弹，**automator 点不到原生弹窗**（实测：指引配好后 `saveImageToPhotosAlbum` 挂 30s 无回调）。
  判据组合（`mp-probe-work/code-step9/dl-only.mjs`）：`downloadFile` 200 + 有 tempFilePath ✓、`requirePrivacyAuthorize` **9ms 返回 ok**（⇒ 声明层已通，不再报 not declared）✓、`getSetting().authSetting` 里**没有** `scope.writePhotosAlbum` ⇒ 用户层尚未点过「允许」⇒ 剩下的挂起是弹窗等待人工，不是缺陷。
- 附带结论：`saveImageToPhotosAlbum` 只吃**本地路径**，远程图必须先 `downloadFile`（www 已在 downloadFile 白名单，D9）；测试图取 `abb988gt` 的 `/_astro/*.webp` 实测 200 可下（webp 能否落相册仍待真机，端上优先给 jpg/png 档）。
